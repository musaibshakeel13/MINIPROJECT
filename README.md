## 🧮 Mini Project — Calculator

I also created a **console-based Calculator** using Java.

The calculator uses:

* `switch-case` for selecting operations
* Multiple arithmetic operations
* `do-while` loop to perform calculations repeatedly
* User input using `Scanner`

### Operations

The calculator can perform multiple operations such as:

* Addition
* Subtraction
* Multiplication
* Division

The user can perform calculations repeatedly and choose when to exit.
